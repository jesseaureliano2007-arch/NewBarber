Motor por dentro
1Motor de cilindros opostos em corte (vista de frente)
Os pistões opostos se movem juntos para fora e para dentro (manivelas a 180°). Cada magneto alimenta uma vela de cada cilindro (linha cheia = superior, tracejada = inferior): se um magneto falhar, todos os cilindros continuam com uma vela.

O came abre a válvula; a mola a fecha.

5Lendo o nome do motor
Iinjeção de combustível Ocilindros opostos 360cilindrada em pol³ -L2Avariante do fabricante
Nomenclatura usual de motores Lycoming/Continental: O = opostos · I = injetado · T = turbo · G = com redução · A = acrobático. Ex.: O-320 = opostos, 320 pol³, carburado; IO-360 = injetado (é o do C172R).
⚠ Pegadinha
Quem fecha a válvula é a mola, não o came. O came só abre.
⇄ Termos
virabrequim = crankshaft · biela = connecting rod · balancim = rocker arm · tucho = lifter
🧠 Memorize
“Ca-Tu-Va-Ba-Vá”: came, tucho, vareta, balancim, válvula.
⚡ Questão relâmpago
Qual peça transforma o movimento alternativo do pistão em rotação?
O conjunto biela + virabrequim (a biela transmite; o virabrequim gira).
