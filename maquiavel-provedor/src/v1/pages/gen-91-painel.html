Como usar o painel
  1. Feche os números até o dia 5 de cada mês, sempre com a mesma fórmula.
  2. Pinte o farol: ● verde na meta · ● amarelo até 20 % fora · ● vermelho pior que isso.
  3. Cada vermelho vira uma ação com dono no Plano de 90 dias.
Metas são referências para um provedor FTTH de ≈ 2.200 clientes, não regras. Compare-se sobretudo com você mesmo, mês a mês.
$Conta rápida · LTV ÷ CAC
ARPU R$ 100 × margem 60 % ÷ churn 1,5 % = LTV ≈ R$ 4.000. Com CAC de R$ 350, cada cliente devolve ≈ 11 vezes o que custou. Com churn de 3 %, o LTV cai para R$ 2.000: a retenção vale tanto quanto a venda.
